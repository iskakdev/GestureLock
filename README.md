# GestureLock

Управление камерой жестами на OpenCV + MediaPipe Hands: сначала пароль пальцами, потом фото и видео по жестам.

## Как работает

Состояния на экране:

- `LOCKED` - заблокировано, жесты не работают;
- `UNLOCKED` - доступ открыт;
- `COUNTDOWN` - обратный отсчёт перед фото или видео.

Пароль задан переменной `password = 8`: нужно показать 8 пальцев (двумя руками, например 5 + 3) и подержать секунду.
Любое другое число пальцев экран не разблокирует.

После разблокировки (жест держать 1 секунду, одной рукой):

| Жест | Действие |
|---|---|
| ✌️ два пальца | отсчёт 3 2 1, фото в `Photos/` |
| 👍 лайк | отсчёт 5 4 3 2 1, видео 5 секунд в `Videos/` |
| 🖐 ладонь | выход из программы |

После каждого действия руку нужно убрать из кадра (на экране `Remove hand`), иначе жест сработал бы повторно.
Выйти можно и клавишей `q`.

Пальцы считаются по расстоянию от запястья: палец поднят, если кончик дальше от запястья, чем средний сустав.
Так счёт не ломается, когда рука повёрнута боком, как при лайке.

## Запуск

Нужен Python 3.12 (mediapipe 0.10.14 со старым API `mp.solutions` не ставится на 3.13+).

```
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Длительность видео, отсчёты и время удержания жеста меняются в начале `main.py`:
`VIDEO_TIME`, `PHOTO_COUNTDOWN`, `VIDEO_COUNTDOWN`, `HOLD_TIME`.
